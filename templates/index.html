Warm Reboot

Soft reboots the microcontroller. Lock state is preserved, but temporary overrides (like LED/Buzzer) are cleared.

Factory Reset / Unassign

Erases all settings, whitelists, and clears the Node ID. The lock will need to be re-provisioned via the unassigned pool.
